# HackerEarth Solutions

## Overview

A small set of HackerEarth practice problems covering brute-force enumeration, number theory and basic math.

## Problems

| Problem | Technique | Code |
|---|---|---|
| Counting Frog Paths | Brute-force enumeration of grid points | [Solution](./Counting%20Frog%20Paths.cpp) |
| Golden Rectangles | Aspect-ratio check | [Solution](./Golden%20rectangles.cpp) |
| Hexadecimal Numbers | Hex digit sum + GCD | [Solution](./Hexadecimal%20numbers.cpp) |

## Compile & run

Each file is a complete program that reads the problem input from stdin:

```bash
g++ -std=c++17 -O2 "Hexadecimal numbers.cpp" -o hex_numbers
./hex_numbers < input.txt
```
